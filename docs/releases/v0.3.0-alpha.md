# Quaid v0.3.0-alpha

## Highlights

- First public alpha release of Quaid.
- Supported host integrations now ship together as the public release surface:
  - OpenClaw
  - Claude Code
  - Codex
- Shared install auth is now simpler:
  - the first install provisions shared credentials
  - later platform installs reuse that shared credential store
- Anthropic-backed lanes are the recommended default for alpha.
- OpenAI-backed lanes remain available, but should be treated as experimental:
  - current live and benchmark results show a meaningful quality drop versus Anthropic
- Installer and AI-install flow were tightened substantially:
  - fixed split-home install layout: hidden `~/.quaid` plus visible `~/quaid`
  - clearer platform-state handling and compatibility warnings
  - cleaner non-blocking progress output during install
  - quieter, more accurate post-install guidance
- Live reliability improved across the launch adapters:
  - OpenClaw daemon recovery now wakes from signal-writing paths, not only prompt paths
  - rolling extraction now budgets on parsed semantic transcript instead of raw JSONL size
  - stale-doc indexing no longer starts ahead of queued extraction signals
  - Codex runtime context now includes `QUAID_HOME` and `QUAID_INSTANCE`
  - OpenClaw runtime now resolves a Python 3.10+ interpreter explicitly instead of depending on shell `PATH`
- Release/docs readiness tightened:
  - compatibility rows recorded for OpenClaw, Claude Code, and Codex from the accepted Run 66 clear
  - installer, user-guide, AI-install, release, and shipped project docs were updated to match current behavior

## Compatibility

- OpenClaw `2026.4.8` — compatible
- Claude Code `2.1.96` — compatible
- Codex `0.118.0` — compatible

## Notes

- Anthropic-backed service lanes are recommended for alpha.
- OpenAI-backed service lanes remain supported but are explicitly experimental.
- Claude Code and Codex both support the core memory path, but they do not expose timeout-based compaction control.
- Codex currently shows injected Quaid context in the host view, which can feel noisy.
- Windows is not supported yet.
- Multi-user hardening and some parallel-session/lifecycle edge cases still need more work.
