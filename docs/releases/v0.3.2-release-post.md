# Quaid v0.3.2 Release Post

Quaid v0.3.2 is a stability release for the installable public line.

This release focuses on making the normal installed runtime more reliable across OpenClaw, Claude Code, and Codex: lifecycle extraction, preserved transcript handling, registry path validation, identity context delivery, and date-bounded recall all received release-readiness fixes.

Validated host lanes:

- OpenClaw 2026.5.2
- Claude Code 2.1.126
- Codex 0.128.0

Run 179 was accepted as the release-readiness run, and the promoted `main` SHA passed GitHub post-promotion gates before release prep.
