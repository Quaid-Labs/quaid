# Quaid v0.3.2

Quaid v0.3.2 is a stability release for the installable public line. It folds the clean Run 179 release-readiness stack into the public release branch.

## Highlights

- Hardened OpenClaw lifecycle delivery for preserved transcripts, matrix channel schema setup, sibling transcript routing, and deferred-notice relay after restore/compact flows.
- Improved daemon extraction reliability for relocated transcripts, zero-size cursor shadows, terminal cursor state, and long extraction runs without a global wall deadline.
- Tightened docs registry CLI behavior: relative paths resolve from the caller cwd, missing files are rejected, and indexing remains asynchronous with clearer operator messaging.
- Cleaned identity context scaffolding so agent-facing identity files carry content, not projection instructions.
- Added `asOf` / `as_of` recall date alias parity and relation-chain recall fixes validated before the release-readiness run.

## Validation

- Run 179 was accepted as the release-readiness run: all milestones passed or met the accepted egregiousness bar, with zero in-run product fixes.
- Full local prepush gate passed at `7f2f76d211ff28ece9348b27297943c123e4bca1`.
- GitHub `Quaid CI` and `CodeQL` passed after promotion to `main`.

## Compatibility

Validated release lanes:

- OpenClaw 2026.5.2
- Claude Code 2.1.126
- Codex 0.128.0

## Known limitations

- Non-English and dense-script recall quality remains active benchmark work and is not yet a release headline claim.
- Some live-test PASS-PWN classifications reflect accepted platform/tester behavior, not release-blocking Quaid runtime failures.
