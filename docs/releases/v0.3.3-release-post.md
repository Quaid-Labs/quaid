# Quaid v0.3.3 Release Post

Quaid v0.3.3 focuses on memory reliability: refined recall ranking, stronger graph/source-chunk recovery, and a new SessionDB foundation for preserving conversation structure behind the memory layer.

This release tightens the path from raw conversation turns through extracted memories, source chunks, session chunks, and later recall. It also includes adapter and daemon hardening for the normal installed runtime across OpenClaw, Claude Code, and Codex.

Validated host lanes:

- OpenClaw 2026.5.2
- Claude Code 2.1.138
- Codex 0.128.0

Run 191 was accepted as the zero-patch green release-readiness run for this stack. The final release metadata and public benchmark README updates are documentation/packaging changes and do not invalidate that clear.
