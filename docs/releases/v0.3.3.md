# Quaid v0.3.3

Quaid v0.3.3 is a post-ship stability release for the 0.3 line. It focuses on memory reliability: refined recall ranking, stronger graph/source-chunk recovery, and a SessionDB foundation for preserving conversation structure behind the memory layer.

## Highlights

- Added the SessionDB bridge and session chunk expansion path so raw conversation turns can be preserved, indexed, and recovered through the normal memory layer.
- Refined recall behavior across relation chains, temporal axes, source chunks, fast inject rescues, and graph/vector/session evidence fusion.
- Hardened extraction daemon recovery for cursor rebases, frozen/empty sessions, rolling-buffer drains, and session-log ingestion edges.
- Improved OpenClaw, Claude Code, and Codex hook behavior around identity refresh, provider notices, prompt injection, and recovery paths.
- Updated public benchmark rows with FC Opus 4.7 comparison data.

## Validation

- Run 191 was accepted as the zero-patch green release-readiness run for this stack.
- Full local prepush gate passed after the final test-only repair on the release stack.
- The release metadata and benchmark README delta are packaging/documentation changes and do not invalidate the clear live-test result.

## Compatibility

Validated release lanes remain:

- OpenClaw 2026.5.2
- Claude Code 2.1.138
- Codex 0.128.0

## Known limitations

- Non-English and dense-script recall quality remains active benchmark work and is not yet a release headline claim.
- Some host-specific behaviors remain platform-limited, especially around Codex hook visibility and async session-boundary timing.
