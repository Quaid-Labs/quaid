# Quaid v0.3.4 Release Post

Quaid v0.3.4 focuses on runtime stability and context preservation. It improves how recall keeps source-backed evidence visible, how extraction recovers after resets or relocated transcripts, and how host adapters deliver identity and notice context before slower background work begins.
