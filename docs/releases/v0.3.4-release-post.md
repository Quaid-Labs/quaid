# Quaid v0.3.4 Release Post

Quaid v0.3.4 focuses on runtime stability and context preservation. It improves how recall keeps source-backed evidence visible, how extraction recovers after resets or relocated transcripts, and how host adapters deliver identity and notice context before slower background work begins.

This is a hardening update for the 0.3 line: fewer missed transcript turns, stronger compact/reset recovery, better source-window grounding, and more reliable OpenClaw and Claude Code hook behavior.

Target host lanes for final release confirmation:

- OpenClaw 2026.5.2
- Claude Code 2.1.138
- Codex 0.128.0

Final compatibility promotion and release publication should happen only after operator review of the release text and the final pre-release gate.
