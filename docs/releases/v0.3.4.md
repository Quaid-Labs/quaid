# Quaid v0.3.4

Quaid v0.3.4 is a stability release for the 0.3 line. It focuses on context preservation: keeping source-backed recall evidence visible, recovering extraction state after host lifecycle churn, and delivering identity or notice context through the right hook surfaces before slower background work begins.

## Highlights

- Strengthened recall source evidence ordering so first-order session and source context stays visible through graph, vector, and mixed-store plans.
- Expanded selected compact source windows while preserving exact lookup behavior and fail-hard contracts.
- Hardened extraction daemon recovery for relocated transcripts, reset re-extraction, stale preserved mirrors, and stale rolling buffers.
- Preserved richer OpenClaw and Matrix transcripts across native transcript rewrites and reset paths so shorter host files do not erase captured user turns.
- Improved OpenClaw and Claude Code compact identity refresh delivery across transition, before-agent-start, and refreshed-rules hook paths.
- Surfaced deferred notices before slower recall/doc work, and tightened janitor and project-doc runtime paths.

## Validation

- Final live validation completed cleanly across the supported host lanes.
- Focused retests passed for the recall, extraction, adapter, hook, janitor, and project-doc fixes included in this release.
- Static validation passed for release metadata, runtime pair generation, privacy scanning, ownership checks, and the targeted release gate.
